# Before-you-deploy checklist

Tick every box before you publish your site.

## Files and folders
- [ ] Home page is named `index.html` (lowercase) and sits in the project root
- [ ] CSS in `css/`, JavaScript in `js/`, images in `img/`
- [ ] File and folder names are lowercase with hyphens, no spaces (`about-us.html`)
- [ ] All links and image paths are **relative** (`img/logo.png`, not `C:\Users\...`)

## Quality
- [ ] Every page has `<title>`, `<meta name="description">` and the viewport tag
- [ ] Every image has meaningful `alt` text and is compressed (under ~200 KB)
- [ ] No errors in the DevTools Console
- [ ] HTML passes <https://validator.w3.org/>
- [ ] Tested at 375 px, 768 px and 1280 px widths
- [ ] Forms show clear error messages

## Publish
- [ ] Code pushed to a public GitHub repository
- [ ] GitHub Pages (or Netlify) is turned on and the live link opens
- [ ] Live link opened on a real phone
- [ ] Live link added to the repository "About" section and to your CV
