# 03 · Bootstrap and jQuery for Responsive Web Pages

![Bootstrap 5](https://img.shields.io/badge/Bootstrap_5-7952B3?style=for-the-badge&logo=bootstrap&logoColor=white) ![jQuery](https://img.shields.io/badge/jQuery_3.7-0769AD?style=for-the-badge&logo=jquery&logoColor=white) ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black) ![GitHub Pages](https://img.shields.io/badge/GitHub_Pages-222222?style=for-the-badge&logo=githubpages&logoColor=white)

> Term 1 (CPISM) · 8 sessions × 2 hours · Build responsive pages fast with Bootstrap 5 and add interactivity with jQuery

## What you will learn

- Why front-end frameworks exist and how to add Bootstrap 5 to a page (CDN or local files)
- Plan any layout with the 12-column grid: containers, rows, columns and breakpoints
- Use ready-made components: buttons, alerts, cards, navbar, modal, carousel, accordion and forms
- Write jQuery code: selectors, events, `$(document).ready()`, show/hide and class changes
- Animate and change the page with jQuery effects and DOM methods, and use plugins and jQuery UI
- Make pages look good on phones, tablets and desktops with Bootstrap utilities
- Combine Bootstrap and jQuery in one project and publish it online for free

## Prerequisites

- HTML5, CSS3 and basic JavaScript from Module 02 (tags, classes, selectors, functions, events)
- Comfortable using VS Code and a browser's DevTools

## Module mini-project

**"Karachi Café" one-page website** built with Bootstrap 5 and jQuery:

- Responsive navbar that collapses on mobile, and a hero section with a call-to-action button.
- Menu section using a grid of cards (1 column on phones, 2 on tablets, 4 on desktops).
- Image carousel for the gallery and an accordion for FAQs.
- "Book a Table" form with Bootstrap styling and jQuery validation (name, phone, date with jQuery UI Datepicker).
- jQuery extras: smooth scrolling for nav links, a "Back to top" button that fades in, and a menu filter (All / Drinks / Food).
- Published on GitHub Pages or Netlify; the link is submitted with the source code.
