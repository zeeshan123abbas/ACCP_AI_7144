> Term 1 (CPISM) · 20 sessions × 2 hours · Build modern, accessible and responsive websites from scratch

## What you will learn

- How the web works: browsers, servers, URLs and HTTP
- Write valid, semantic HTML5: text, links, lists, images, tables, forms, audio and video
- Style pages with CSS3: selectors, box model, positioning, Flexbox, Grid, subgrid, nesting and animation
- Make pages responsive and mobile-friendly
- Program the browser with modern JavaScript (ES2022+): variables, functions, objects, DOM, events, JSON
- Use HTML5 APIs: Canvas, Web Storage, IndexedDB, Geolocation and Drag and Drop
- Build a complete mini project that combines HTML, CSS and JavaScript

## Prerequisites

- Basic computer and file management skills (Module 01)
- No previous programming experience needed

## Module mini-project

**"City Explorer"** - a responsive multi-page website about your city (e.g. Karachi):

- `index.html` with semantic layout (header, nav, main, footer) and a hero section with CSS animation.
- `places.html` with a CSS Grid gallery of at least 6 places (images with alt text and captions).
- `events.html` with an accessible table of upcoming events and an embedded video.
- `contact.html` with an HTML5 form (validation, new input types) and a map link using the Geolocation API ("Find places near me").
- JavaScript: a dark/light theme toggle saved in `localStorage`, a search filter for places, and data loaded from a `places.json` file with `fetch`.
- Must pass the W3C validator and look good on mobile, tablet and desktop.
