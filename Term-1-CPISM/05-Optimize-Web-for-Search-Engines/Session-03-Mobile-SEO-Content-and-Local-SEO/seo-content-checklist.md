# SEO-friendly Content Checklist

Tick each item before you publish a page or blog post. Score: 1 point per tick.

## Planning
- [ ] I know the **one main keyword** and the **search intent** (learn / compare / buy / go to)
- [ ] I searched the keyword and studied the top 5 results (what do they cover?)
- [ ] My page adds something new: own example, photo, data, local detail or experience

## Title, URL and description
- [ ] Title is unique, 50-60 characters, keyword near the start
- [ ] URL is short, lowercase, uses hyphens: `/blog/what-is-responsive-design`
- [ ] Meta description is 120-155 characters with a call to action

## Body
- [ ] Exactly one `<h1>`; `<h2>`/`<h3>` in a logical order
- [ ] The main question is answered in the first 100 words
- [ ] Short paragraphs (2-4 lines), lists and tables where useful
- [ ] Keyword and related terms used naturally (read it aloud: does it sound human?)
- [ ] At least one question heading with a 40-60 word direct answer (featured snippet chance)
- [ ] Author name and "last updated" date shown

## Media
- [ ] Images compressed (WebP/AVIF), descriptive file names and `alt` text
- [ ] `width` and `height` set; images below the fold use `loading="lazy"`
- [ ] Videos have a title, description and transcript

## Links
- [ ] 2-5 internal links to related pages with descriptive anchor text
- [ ] 1-2 external links to trusted sources (official docs, research)
- [ ] Linked from the pillar page / menu so bots can find it

## Final checks
- [ ] Spell-checked and readable for a 14-year-old (simple words)
- [ ] Looks good on a phone (DevTools device mode)
- [ ] Lighthouse SEO score 90+
