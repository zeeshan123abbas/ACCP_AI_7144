# AI Prompts for SEO Work (edit every result yourself)

Replace the text in [square brackets]. Never paste passwords, private client data or analytics exports with personal data.

## 1. Keyword and topic ideas
```
I run [a computer training institute in North Nazimabad, Karachi].
List 20 search queries real people might type when looking for [a web design course].
Group them by search intent: informational, commercial, transactional.
Do not invent search volumes.
```
Then check the volumes in a real keyword tool.

## 2. Meta descriptions
```
Write 3 meta descriptions for a page titled "[Evening Web Design Course North Nazimabad]".
Each must be 130-155 characters, include the phrase "[web design course]" once,
mention one benefit, and end with a call to action. Use simple English.
```
Count the characters and check every claim is true.

## 3. FAQ ideas for a page
```
Suggest 6 questions a beginner might ask before joining [a 12-week web design course].
Give each a 40-60 word answer in simple English. Mark any answer that needs facts I must confirm.
```

## 4. Article outline (topic cluster)
```
Create an outline for a blog post "[What Is Responsive Web Design?]" for beginners in Pakistan.
Include an H1, 5-7 H2 headings, one comparison table idea and 3 internal link ideas
to related posts: [CSS Flexbox vs Grid], [Publishing on GitHub Pages].
```

## 5. Alt text drafts
```
Write short, descriptive alt text (max 125 characters) for these images:
1. [Photo: students working on laptops in a lab]
2. [Photo: teacher pointing at HTML code on a projector]
Do not start with "image of".
```

## 6. Explain an audit in plain English
```
Rewrite these SEO audit findings for a shop owner with no technical background.
Keep each point to one sentence and say why it matters for customers:
[paste your issue list, without private data]
```

## Human checklist after using AI
- [ ] Facts, prices, dates and names verified
- [ ] Length limits checked (title, description, alt text)
