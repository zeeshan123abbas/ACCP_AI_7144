## Week 1 - Foundation
- [ ] Day 1: Run the full audit (`seo-audit-checklist.md`)
- [ ] Day 2: Verify Search Console + Bing Webmaster Tools; install GA4; link GA4 with Search Console
- [ ] Day 3: Fix all **Critical** issues (noindex, broken pages, HTTPS)
- [ ] Day 4: Create/clean `robots.txt` and `sitemap.xml`; submit sitemap
- [ ] Day 5: Set key events (form submit, WhatsApp click); record KPI baseline

## Week 2 - On-page
- [ ] Day 8: Keyword research and keyword map for all main pages
- [ ] Day 9-10: Rewrite titles, meta descriptions and H1s
- [ ] Day 11: Improve internal links and fix image alt text
- [ ] Day 12: Add Organization/LocalBusiness and Breadcrumb JSON-LD; validate

## Week 3 - Content and local
- [ ] Day 15: Plan a topic cluster (1 pillar + 4 posts)
- [ ] Day 16-18: Publish 2 helpful posts (use the content checklist)
- [ ] Day 19: Complete Google Business Profile; check NAP everywhere
- [ ] Day 20: Ask 10 happy customers for reviews; reply to all reviews

## Week 4 - Off-page and social
- [ ] Day 22: Turn each new post into 3 social posts with UTM links
- [ ] Day 23-24: Send 5 outreach emails (partners, local blogs, directories)
- [ ] Day 25: Use AI to draft FAQ ideas; edit and add to key pages
- [ ] Day 29: Measure KPIs against baseline
- [ ] Day 30: Write a 1-page progress report and plan the next month
