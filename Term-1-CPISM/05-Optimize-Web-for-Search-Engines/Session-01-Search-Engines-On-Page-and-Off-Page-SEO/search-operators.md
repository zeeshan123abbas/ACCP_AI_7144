Type each query into Google. Write what you found in the last column.

| # | Query | What it finds | My result |
|---|-------|---------------|-----------|
| 1 | `"responsive web design"` | Pages with this exact phrase | |

| 10 | `"best * in Karachi"` | Fills the * with any word (biryani, school...) | |
| 11 | `site:example.com -site:www.example.com` | Sub-domains of a site (e.g. blog.example.com) | |
| 12 | `"karachi tech hub" -site:karachitechhub.com` | Mentions of a brand on other sites (link ideas!) | |

## SEO uses

- **Index check:** `site:yourdomain.com` shows roughly how many pages Google has stored.
- **Competitor research:** `site:competitor.com intitle:course` shows their course pages.
- **Link building:** query 12 finds sites that mention you but may not link to you yet.
- **Content gaps:** `intitle:"how to" topic` shows which questions people write about.

> The numbers Google shows for `site:` are estimates. Use Search Console for exact index data.
