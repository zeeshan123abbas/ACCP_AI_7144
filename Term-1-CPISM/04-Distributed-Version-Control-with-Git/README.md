> Term 1 (CPISM) · 6 sessions × 2 hours · Track every change, work in teams and automate deployment with Git, GitHub, Copilot and Actions

## What you will learn

- Why version control exists, and the difference between centralised and distributed systems
- The difference between Git (the tool) and GitHub (the website)
- The everyday Git cycle: `init`, `status`, `add`, `commit`, `log`, `push`, `pull`
- Write clean commit messages and ignore files with `.gitignore`
- Undo mistakes safely with `restore`, `reset`, `revert` and `commit --amend`
- Work in teams with branches, merges, pull requests, forks, rebase, stash and tags
- Resolve merge conflicts calmly
- Use GitHub Copilot responsibly and automate checks and deployment with GitHub Actions

## Prerequisites

- Basic file and folder skills (Module 01)

## Module mini-project

**"Team Portfolio" repository** (groups of 2-3):

- One public repository with a `README.md`, a `.gitignore` and a small Bootstrap website (one page per member).
- Each member works on a **feature branch** and opens a **pull request**; another member reviews and merges it.
- At least one merge conflict created on purpose and resolved, explained in the PR description.
- At least 10 meaningful commits that follow the Conventional Commits style (`feat:`, `fix:`, `docs:`).
- A version tag `v1.0.0` and a GitHub Release.
- A GitHub Actions workflow that checks the HTML on every push and deploys the site to GitHub Pages.
- Submit the repository link and the live Pages URL.
