# GitHub Copilot practice prompts

Try each prompt in VS Code. **Read and test every suggestion before you keep it.**

## 1. Inline suggestions (type a comment, press Enter, wait, press Tab to accept)
```html
<!-- Bootstrap 5 card with an image, title "Physics", short text and a "Join" button -->
```
```js
// function that returns true if a Pakistani mobile number like 03001234567 is valid
```

## 2. Copilot Chat (Ctrl+Alt+I) - ask questions
- "Explain what this jQuery code does, line by line." (select the code first)
- "Why does my navbar not collapse on mobile?" (select the navbar HTML)
- "Suggest a better commit message for these changes."

## 3. Slash commands in Chat
| Command | Use |
|---------|-----|
| `/explain` | Explain the selected code |
| `/fix` | Suggest a fix for an error |
| `/doc` | Add comments / documentation |
| `/tests` | Generate tests (for JavaScript functions) |

## 4. Git helpers
- In the **Source Control** panel click the ✨ sparkle icon to generate a commit message.
- On github.com, Copilot can summarise a pull request (where available on your plan).

## Responsible use rules
1. You are the author: never submit code you cannot explain.
2. Check for errors, security problems and outdated code (e.g. Bootstrap 4 classes).
3. Never paste passwords, API keys or private data into a prompt.
4. Follow your institute's rules about AI in assignments; say when you used it.
