> Term 4 (HDSE) · 12 sessions × 2 hours · [⬅ Term Home](../README.md)

This module turns you into a confident React developer. You start with the core ideas (components, JSX, props and state), move on to events, hooks, routing, styling and the component lifecycle, and finish by building CRUD screens and AI-powered features. Every session folder contains runnable `.jsx` files you can drop into a Vite playground.

## 🎯 What You Will Learn

- Build user interfaces from reusable function components and JSX
- Pass data with props and callbacks, and manage state with hooks
- Handle user events and build controlled, validated forms
- Create multi-page SPAs with React Router
- Style components with CSS, CSS Modules and Bootstrap
- Fetch external data safely with `useEffect`
- Build complete CRUD applications against a REST API
- Integrate AI APIs securely through a backend proxy

## 📋 Prerequisites

- HTML5 and CSS3 (Term 1)
- Modern JavaScript: `let/const`, arrow functions, arrays (`map`, `filter`, `reduce`), objects, destructuring, spread, modules, Promises and `async/await` (Term 2)
- Basic command-line usage and Git

## 🚀 Module Mini-Project

**Course Portal SPA** - build a small portal for your batch:

1. Routes: Home, Courses (list), Course detail (`/courses/:id`), Notes (CRUD), Ask AI, 404.
2. Course data loaded from a json-server REST API with loading/error states.
3. Notes CRUD with validation, stored on the API.
4. Styled with CSS Modules (or Bootstrap 5) and a dark/light theme toggle.
5. An "Ask AI" page that talks to your Node proxy (key kept on the server).
6. Deployed to a static host, with a README containing screenshots and setup steps.
