# UI Review Checklist

Use this list to review any screen (yours or a classmate's). Tick each item.

## Clarity
- [ ] The main purpose of the screen is clear within 5 seconds
- [ ] There is one obvious primary action (one filled button)
- [ ] Headings, body text and labels look different (visual hierarchy)

## Consistency
- [ ] The same colours, fonts and corner radius are used everywhere
- [ ] Buttons with the same job look the same on every screen
- [ ] Icons come from one icon set

## Feedback
- [ ] Every click/tap shows a visible response (state change, ripple, message)
- [ ] Loading and error states are designed, not left empty
- [ ] Success is confirmed (snackbar, message, check mark)

## Accessibility
- [ ] Text contrast is at least 4.5:1 (use a contrast checker)
- [ ] Touch targets are at least 48 × 48 dp
- [ ] Information is not shown by colour alone
- [ ] Form fields have visible labels, not only placeholders

## Layout
- [ ] Spacing follows an 8 dp grid (8, 16, 24, 32 ...)
- [ ] The screen works on a phone, a tablet and a desktop
- [ ] Related items are grouped; unrelated ones have more space between them
