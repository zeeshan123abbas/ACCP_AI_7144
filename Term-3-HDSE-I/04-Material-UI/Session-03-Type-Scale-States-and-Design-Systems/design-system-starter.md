# Design System Starter Template

Use this template to document a small design system for your project (eProject or mini-project).

## 1. Principles (3–5 short sentences)
- Example: "Clear before clever: every screen has one primary action."

## 2. Tokens
| Token | Value | Use |
|---|---|---|
| color.primary | #6750A4 | main buttons, active states |
| color.on-primary | #FFFFFF | text on primary |
| color.surface | #FEF7FF | page background |
| color.error | #B3261E | errors |
| shape.corner.medium | 12px | cards |
| space.unit | 8px | all spacing is a multiple |

## 3. Typography
| Role | Size / line height | Weight | Use |
|---|---|---|---|
| Headline Small | 24 / 32 | 400 | page titles |
| Title Medium | 16 / 24 | 500 | card titles |
| Body Medium | 14 / 20 | 400 | normal text |
| Label Large | 14 / 20 | 500 | buttons |

## 4. Components (one row per component)
| Component | Variants | States designed | Do | Don't |
|---|---|---|---|---|
| Button | filled, outlined, text | enabled, hover, focus, pressed, disabled | one filled button per screen | two filled buttons side by side |
| Text field | outlined | enabled, focus, error, disabled | label above / floating | placeholder as the only label |

## 5. Accessibility rules
- Contrast 4.5:1 for text, 3:1 for large text and UI parts
- Visible focus ring on all interactive elements
- Touch targets 48 × 48 dp minimum
