> Term 3 (HDSE I) · 3 sessions × 2 hours · Skill: designing clear, consistent and accessible interfaces with Material Design

## What You Will Learn

- The difference between UI and UX, and the principles behind a good interface
- How to design for real users with personas and a simple user-centred process
- Material Design 3 foundations: surfaces, elevation, colour roles, shape, layout and motion
- Design tokens (reference, system, component) and how they become CSS custom properties
- Designing and prototyping screens in Figma with the Material 3 Design Kit and Theme Builder
- Choosing the right input controls, using the type scale, and designing every component state
- What a design system is, and how to document a small one for your own project

## Prerequisites

- HTML and CSS basics (Terms 1–2)
- Helpful: Module 03 (you used Angular Material components there; this module explains the design behind them)

## Module Mini-Project: Campus Events App Design

1. **Research** – two personas and the top three tasks for each.
2. **Tokens** – generate a scheme in Material Theme Builder from your college colour; export light and dark CSS.
3. **Figma** – design four mobile screens (Event list, Event details, Register form, Success) using the Material 3 Design Kit, auto layout and an 8 dp grid.
4. **States** – design hover, focus, pressed, disabled and error states for the button and text field.
5. **Prototype** – link the screens into a clickable flow.
6. **Code** – build the Register screen in HTML/CSS (or Angular Material) using only token variables and the type scale.
7. **Document** – fill the design system starter template and review your screens with the UI checklist.
