# Build and Manage Websites with CMS

![WordPress](https://img.shields.io/badge/WordPress-6.5%2B-21759b?logo=wordpress&logoColor=white) ![PHP](https://img.shields.io/badge/PHP-8.x-777bb4?logo=php&logoColor=white) ![MySQL](https://img.shields.io/badge/MySQL-8-4479a1?logo=mysql&logoColor=white) ![Elementor](https://img.shields.io/badge/Elementor-optional-92003b?logo=elementor&logoColor=white) ![Google Analytics](https://img.shields.io/badge/Google%20Analytics-GA4-e37400?logo=googleanalytics&logoColor=white)

> Term 2 (DISM) · 8 sessions · ⏱ ~2 hours each

Many clients do not need a custom-coded application; they need a professional website they can update themselves. In this module you will plan, build, optimise, secure and maintain WordPress websites — from installation and themes to plugins, SEO, analytics, custom post types and AI-assisted content — and finish with a complete client-ready site.

## What You Will Learn

- Explain CMS concepts and compare WordPress, Joomla, Drupal and Shopify
- Install WordPress manually on a local server
- Customise themes with the Site Editor, Customizer and child themes
- Extend sites with plugins, widgets and a small custom plugin
- Create pages, posts, galleries, embeds and forms
- Optimise SEO, speed and mobile experience
- Add analytics, harden security and manage backups
- Build custom post types, add chatbots and use AI responsibly

## Prerequisites

- HTML and CSS basics
- PHP and MySQL basics (Modules 03–04) help with customisation

## Module Mini-Project

**Client website.** Choose a local client (coaching centre, clinic, restaurant or NGO) and deliver: homepage, about, services/courses (custom post type), blog with categories, contact page with form and map, gallery, chatbot, SEO setup with sitemap, Google Analytics, caching, security hardening and an off-site backup. Provide a short user guide so the client can add posts themselves.
