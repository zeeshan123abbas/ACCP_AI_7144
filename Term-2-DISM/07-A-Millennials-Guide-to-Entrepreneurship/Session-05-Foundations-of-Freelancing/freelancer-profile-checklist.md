# Freelancer Profile Checklist

Use this before publishing your Fiverr gig, Upwork profile or LinkedIn profile.

## 1. Identity and trust
- [ ] Real name exactly as on your CNIC and payment account
- [ ] Clear, friendly, professional headshot (plain background, face visible)
- [ ] Identity verification completed on the platform
- [ ] Same photo and name on LinkedIn, GitHub and platform profile

## 2. Title (headline)
- [ ] Says WHO you help and WHAT you deliver (not just "Web Developer")
- [ ] Includes 1–2 keywords clients search for
- Example: `WordPress Developer | Fast, Mobile-Friendly Websites for Clinics & Small Businesses`
- Example: `Laravel & PHP Developer | Admin Dashboards, CRUD Apps, MySQL`

## 3. Overview / description
- [ ] First 2 lines speak to the client's problem (they show in search previews)
- [ ] Lists 3–5 services in bullet points
- [ ] Mentions tools/technologies (PHP 8, Laravel, WordPress, MySQL, Bootstrap 5, JavaScript)
- [ ] Explains your process (requirements → design → build → test → deliver → support)
- [ ] Ends with a call to action ("Message me with your project details")
- [ ] No spelling mistakes (check with a grammar tool)
- [ ] No phone numbers, emails or outside links where the platform forbids them

## 4. Portfolio (3–5 items)
- [ ] Each item has a cover image/screenshot
- [ ] Each item states: problem, what you built, technologies, result
- [ ] Live demo link and/or GitHub link works
- [ ] Only your own work (or clearly marked team work)

## 5. Skills and tags
- [ ] Skills match your niche (5–10, most important first)
- [ ] Gig tags use real search terms ("wordpress website", "laravel developer")

## 6. Packages / rate (Fiverr gig or Upwork rate)
- [ ] Basic / Standard / Premium with clear differences
- [ ] Delivery days and number of revisions stated
- [ ] Price calculated with `rate_calculator.py`, including platform fee
- [ ] FAQ section answers 3–5 common questions

## 7. Extras
- [ ] Short intro video (60–90 s) if possible
- [ ] Skill tests or certificates added (e.g. Aptech, DigiSkills.pk)
- [ ] Availability and response time set realistically
- [ ] Payoneer or bank withdrawal method added and verified

## 8. Safety
- [ ] Never share your password or verification codes with anyone
- [ ] Never use or rent someone else's account
- [ ] Keep all payments and chats on the platform
