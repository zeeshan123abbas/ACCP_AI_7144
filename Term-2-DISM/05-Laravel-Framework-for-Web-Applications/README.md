# Laravel Framework for Web Applications using PHP

![Laravel](https://img.shields.io/badge/Laravel-11-ff2d20?logo=laravel&logoColor=white) ![PHP](https://img.shields.io/badge/PHP-8.2%2B-777bb4?logo=php&logoColor=white) ![MySQL](https://img.shields.io/badge/MySQL-8-4479a1?logo=mysql&logoColor=white) ![Bootstrap](https://img.shields.io/badge/Bootstrap-5.3-7952b3?logo=bootstrap&logoColor=white) ![Composer](https://img.shields.io/badge/Composer-2-885630?logo=composer&logoColor=white)

> Term 2 (DISM) · 8 sessions · ⏱ ~2 hours each

After building applications in plain PHP you know how much code goes into routing, validation, security and database access. Laravel gives you all of that out of the box. In eight sessions you will set up a professional environment, learn MVC, Blade, migrations and Eloquent, build full CRUD with validation and finish with an authenticated blog application.

## What You Will Learn

- Install and run Laravel 11 with Composer (and understand Homestead/Sail)
- Explain MVC and navigate Laravel's structure with Artisan
- Create routes, Blade layouts and forms with CSRF protection
- Design databases with migrations, factories and seeders
- Use Eloquent ORM, relationships, scopes and soft deletes
- Build resource controllers with Form Request validation and pagination
- Add authentication, middleware, roles and policies

## Prerequisites

- PHP 8 including OOP and PDO (Module 04)
- MySQL (Module 03)
- HTML, CSS, Bootstrap and basic JavaScript

## Module Mini-Project

**Course Enrollment Portal (Laravel).** Students register and log in (Breeze), browse courses by category, enroll (many-to-many with pivot `enrolled_at`), and see their dashboard. Admins manage courses and categories through resource controllers with Form Request validation, image upload (`storage:link`), pagination and soft deletes. Include seeders with realistic data and a README with setup steps.
