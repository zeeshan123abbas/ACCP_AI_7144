> Term 2 (DISM) · 12 sessions · ⏱ ~2 hours each

You already know JavaScript basics from Term 1. This module takes you to a professional level: structuring large apps with classes and modules, handling data and errors like a pro, writing non-blocking and high-performance code, using real build tools, debugging with DevTools, exploring modern frameworks, and adding AI and emerging browser features to your projects.

## What You Will Learn

- Write clean, modular code with classes and ES modules
- Process data with regex, modern array methods, Map/Set and safe null handling
- Master the event loop, Promises, async/await and the Fetch API
- Optimise performance with lazy loading, Web Workers, debounce and throttle
- Set up Babel and Webpack with tree shaking and code splitting
- Debug efficiently with Chrome DevTools and test across browsers
- Compare Vue, Svelte and SolidJS and build a Vue app with routing and state
- Add AI with TensorFlow.js and use modern Web APIs

## Prerequisites

- HTML5 and CSS3
- JavaScript fundamentals: variables, conditions, loops, functions, DOM basics
- Data Processing with XML and JSON (Module 01)

## Module Mini-Project

**Smart Student Portal (front-end only).** Combine everything from this module:

1. Modular structure (`models/`, `services/`, `ui/`, `utils/`) built with Webpack + Babel.
2. Student records loaded from `https://jsonplaceholder.typicode.com/users` with loader, timeout and error states.
3. Regex validation for an admission form (email, mobile, CNIC).
4. Debounced live search and a lazy-loaded photo gallery.
5. A "Reports" view loaded with dynamic `import()` that computes statistics in a Web Worker.
6. Voice search using the Web Speech API (with feature detection).
7. A Bundle Analyzer screenshot and a short `PERFORMANCE.md`.
